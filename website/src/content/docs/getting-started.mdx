This guide walks through setting up Coral and managing capabilities in a project.

Before you initialize anything, `coral` gives you a quick overview of the CLI:

![Coral CLI welcome output](/img/generated/coral-welcome.png)

## 1. Initialize Coral

```sh frame="terminal"
coral init
```

Creates `.coral/` state, registers `open-agents`, scaffolds `.agents/` directories, and auto-installs
`coral-cli-guide`, a reference skill your coding agent can read to learn Coral commands.

## 2. Register agent harnesses

```sh frame="terminal"
coral agent add open-agents
coral agent add claude
```

## 3. Create and track your first capability

```sh frame="terminal"
coral create skill my-skill
```

Coral creates a valid starter scaffold in `.agents/skills/my-skill/` so you can edit the generated
files instead of writing boilerplate from scratch.

Use `--agent claude` to scaffold and track under `.claude/` instead:

```sh frame="terminal"
coral create skill my-skill --agent claude
```

The command records the baseline and starts tracking drift without requiring a separate import.

If your project already has a skill under `.agents/skills/`, add it in place:

```sh frame="terminal"
coral add .agents/skills/existing-skill -a open-agents
```

## 4. Inspect what is installed

```sh frame="terminal"
coral list
```

`coral list` now shows a table with the capability type, agent, status, and path.

## 5. Edit and detect drift

```sh frame="terminal"
coral list
coral diff my-skill
```

After you edit `.agents/skills/my-skill/SKILL.md`, `coral list` will show it as modified and
`coral diff my-skill` will show the tracked changes.

If the drift is intentional and you want Coral to treat the edited version as the new baseline,
accept the local edits with `coral update`:

```sh frame="terminal"
coral update my-skill
```

For a capability installed on multiple agents, use `-t/--agent` to update only selected agents.
For existing files that were added in place, later edits follow this same drift and update flow.

## 6. Install from git

```sh frame="terminal"
coral add https://github.com/pproenca/dot-skills --skill rust-implement -a open-agents
```

Use this when the capability already lives in another repository and you want Coral to install and
track it in your project.

## 7. Check for updates

```sh frame="terminal"
coral outdated
coral update rust-implement
```

`coral outdated` compares tracked git-backed capabilities against their latest upstream revision,
and `coral update` reconciles them when you are ready.

## 8. Clean up a capability

Delete files Coral generated for an agent:

```sh frame="terminal"
coral delete rust-implement -a open-agents
```

If the capability was added from files you already owned, preserve those files and remove only
Coral tracking:

```sh frame="terminal"
coral untrack my-skill -a open-agents
```

`coral agent remove open-agents` only unregisters the agent. It does not remove capabilities.

## 9. CI validation

```sh frame="terminal"
coral check
# ✓ coral-cli-guide    skill    open-agents    ok
# ✓ my-skill           skill    open-agents    ok
```
