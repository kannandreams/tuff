Coral is shaped by a mix of open-source libraries, documentation tooling, and prior work in the
agent capability space.

## Project inspiration

- [skills.sh](https://skills.sh/) for the broader idea of reusable, shareable agent skills

## Documentation and docs UX

- [Astro](https://astro.build/) for the docs site framework
- [Starlight](https://starlight.astro.build/) for the documentation theme and navigation structure
- [Pagefind](https://pagefind.app/) for local search in the generated docs
- [freeze](https://github.com/charmbracelet/freeze) for terminal screenshots generated from real CLI output

## CLI and implementation

- [clap](https://github.com/clap-rs/clap) for command-line parsing
- [tabled](https://github.com/zhiburt/tabled) for tabular CLI output
- [diffy](https://github.com/bmwill/diffy) for merge-aware updates and diff handling
