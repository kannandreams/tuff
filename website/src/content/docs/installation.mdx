## Quick install

<Tabs syncKey="install-method">
  <TabItem label="Homebrew">

  ```sh
  brew tap kannandreams/homebrew-tuff
  brew install tuff
  ```

  Requires [Homebrew](https://brew.sh).

  </TabItem>
  <TabItem label="curl">

  ```sh
  curl -fsSL https://raw.githubusercontent.com/kannandreams/tuff/main/install.sh | sh
  ```

  Downloads the latest release binary for your OS and architecture.

  </TabItem>
  <TabItem label="cargo">

  ```sh
  cargo install tuffcli
  ```

  Builds from source. Requires Rust and Cargo.

  </TabItem>
  <TabItem label="Build from source">

  ```sh
  git clone https://github.com/kannandreams/tuff
  cd tuff
  cargo build -p tuffcli --release
  ./target/release/tuff --version
  ```

  Clone and build locally.

  </TabItem>
</Tabs>

## Verify

```sh frame="terminal"
tuff --version
tuff
```

## Requirements

- **Rust**: `cargo` and build methods use it directly. `curl` and `brew` methods install prebuilt binaries.
- **Git**: required for `tuff add` with git-backed capabilities.

## Installed Files

- `/usr/local/bin/tuff` (curl/brew methods)
- user cache directory: disposable verified capability trees
- project root: `tuff.lock` and optional `tuff.config.json`
