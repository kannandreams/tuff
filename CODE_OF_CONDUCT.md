# Code of Conduct

## Our Pledge

We want Tuff to be a welcoming and useful project for people building agent
capability tooling. We expect everyone participating in issues, discussions,
pull requests, and other project spaces to be respectful, constructive, and
patient.

## Expected Behavior

- Use welcoming and inclusive language.
- Respect different experience levels and viewpoints.
- Give feedback that is specific, actionable, and kind.
- Assume good intent, and ask for clarification before escalating a
  disagreement.
- Keep discussions focused on the project and the work at hand.

## Unacceptable Behavior

- Harassment, insults, threats, or personal attacks.
- Discriminatory language or conduct.
- Publishing private information without explicit permission.
- Repeated disruption of project discussions.
- Any other behavior that maintainers reasonably consider inappropriate in a
  professional open source community.

## Enforcement

Maintainers may remove comments, close discussions, reject contributions, or
temporarily or permanently restrict participation when behavior violates this
code of conduct.

If you need to report a concern, contact the maintainers through the project
repository. Reports will be handled with care and discretion.
